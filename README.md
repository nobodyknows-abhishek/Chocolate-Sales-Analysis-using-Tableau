## 📌 Project Overview

This project transforms raw sales data into actionable business insights — enabling visualization of:

- Country-wise revenue performance  
- Product demand and popularity  
- Monthly sales trends  
- Salesperson performance comparisons  
- Geographical distribution of sales  
- Product preference patterns across different regions  

With this dashboard, decision-makers can quickly detect high-performing markets/products as well as lagging ones and make data-driven decisions about marketing, distribution, inventory, and more.
